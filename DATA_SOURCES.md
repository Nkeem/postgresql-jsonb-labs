# Источники и воспроизводимость

## ЛР1: авиаперевозки

- Источник: [демобаза Postgres Professional](https://postgrespro.ru/education/demodb).
- Архив: [demo-small.zip](https://edu.postgrespro.ru/demo-small.zip), версия от 15.08.2017.
- Файл в архиве: `demo-small-20170815.sql`.
- SHA-256 проверенного архива:
  `4fb07944ea715f93e9cafb9173ef9b594be377d8eda984cbce29d8866ea32632`.

В репозиторий включены SQL лабораторной и результаты проверок. Сам архив
скачивает `scripts/prepare_demo.py`. Из дампа удаляются только `DROP DATABASE demo;`
и `SET default_with_oids = false;`. Схема и исходные данные сохраняются.
Несовпадение контрольной суммы останавливает подготовку.

Готовый архив можно передать без скачивания:

```sh
python scripts/prepare_demo.py --archive /path/to/demo-small.zip
```

## ЛР2: стартапы

- Источник: публичные HTML-страницы [Failory Startups](https://www.failory.com/startups).
- Снимок: 02.11.2026, 37 использованных страниц, 363 подробные карточки.
- [Manifest](lab2/source/manifest.json) содержит URL, время получения, имя файла,
  SHA-256 исходных байтов и число карточек каждой страницы.
- [JSON Schema](lab2/data/startups.schema.json) описывает структуру записей.
- [Сводка сбора](lab2/data/collection_summary.json) фиксирует пропуски и валютные метки.

HTML сохранён для воспроизведения извлечения и проверки происхождения записей.
Файлы HTML не преобразуются Git при смене ОС, чтобы сохранить их SHA-256.
`denmark.html` — кеш отклонённой страницы; причина исключения записана
в [collection_issues.json](lab2/results/collection_issues.json).

Выборка ограничена фиксированным порядком стран и порогом 360 уникальных записей.
Она не представляет весь мировой рынок. Данные не проходили финансовый аудит.
Неизвестные значения сохраняются как `null` или пустой массив; годы основания
не превращаются в выдуманные даты. Валютная метка `$` не переименовывается в USD,
валюты не конвертируются.

Исходные данные, тексты HTML и материалы сторонних источников принадлежат
их правообладателям; ссылки на источники сохраняются в данных и документации.
