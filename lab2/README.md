# ЛР2: каталог стартапов, вариант 14

**Цель:** извлечь сведения из HTML, очистить их, сохранить в JSON и выполнить
ровно три простых и два расширенных запроса к JSONB в PostgreSQL.

[PDF-отчёт](output/pdf/report.pdf) · [Набор данных](data/startups.json) · [SQL-запросы](02_queries.sql)

## Результат

- 363 уникальных компании с 37 использованных страниц, 37 стран.
- 24 проверки: очистка, типы полей, SHA-256 HTML и повторное извлечение карточек.
- Полные результаты всех пяти SQL-запросов сверены с расчётами на JSON в Python.
- Повторная загрузка не добавляет дубли и не меняет существующие документы.

## Конвейер

```text
HTML Failory → подробные карточки → нормализация → дедупликация
    → startups.json → lab2.startups_json → пять SQL-запросов
```

Парсер использует стандартную библиотеку Python. Извлекаются заголовки
`failory-card-title`, отраслевые метки `failory-badge` и таблицы `info-table`.
Компактные таблицы без основателей не используются.

Страна берётся из Headquarters. Очистка нормализует Unicode и пробелы,
убирает tracking-параметры URL, разделяет имена основателей и удаляет повторы
в массивах. Идентификатор вычисляется из имени и домена сайта; при отсутствии
сайта используется имя и страна. Числа K/M/B переводятся через `Decimal`.

## Запросы

| Файл | Назначение | Результат снимка |
|---|---|---|
| [Q1](queries/Q1_count.sql) | Число документов и пропуски | 363 записи; 33 без основателей; 15 без суммы |
| [Q2](queries/Q2_india.sql) | Индия, год основания от 2015 | 7 компаний |
| [Q3](queries/Q3_ai.sql) | Точное наличие тега AI в массиве | 89 компаний |
| [Q4](queries/Q4_sector_statistics.sql) | Статистика по стране, отрасли и валютной метке | 198 групп |
| [Q5](queries/Q5_top3.sql) | Не более трёх компаний по сумме в каждой группе страна / валютная метка | 129 строк |

Q4 использует `LATERAL` для раскрытия массива отраслей и убирает повторы
отрасли внутри компании. `COUNT(amount)`, `SUM` и `AVG` сохраняют смысл
неизвестных сумм. Q5 применяет `ROW_NUMBER` со стабильным порядком по сумме,
имени и идентификатору.

## Запуск и проверка

Из корня репозитория после `docker compose up -d --wait`:

```sh
python scripts/run_labs.py --backend docker --lab 2
python scripts/verify_labs.py --backend docker --lab 2
```

Демобаза и ЛР1 для второй работы не нужны. Без Docker используйте те же
команды без `--backend docker`. В pgAdmin выполните `01_load_data.sql`,
затем отдельные файлы из `queries/` для просмотра каждого результата.

Повторный сбор сохранённых страниц:

```sh
python lab2/01_collect.py
```

Сохранённые страницы позволяют повторить исходную выборку без сети.
Для нового снимка используйте `--refresh`; он перезапишет данные, manifest
и загрузочный SQL, поэтому результаты могут отличаться от отчёта.
Исходная страница Дании исключена; её кеш сохранён для воспроизведения причины отказа.

## Ограничения данных

У двух компаний неизвестен год основания. Источник даёт год, поэтому
`foundation_date` остаётся `null`, точность указана в `foundation_precision`.
33 списка основателей пусты, 15 сумм неизвестны или не распознаны,
один сайт заменён на `null` из-за значения `#`.

Funding Amount — заявленная источником сумма финансирования.
Сохраняются исходная строка и валютная метка; `$` не подменяется USD,
конвертация валют не выполняется. Агрегаты разделены по метке, но одинаковый
символ не гарантирует финансовую сопоставимость. Компания может входить
в несколько отраслей, поэтому суммы отраслевых групп нельзя складывать.
Выборка учебная и не представляет весь рынок.
